# Переход на всю Россию: замеры и решения (этап 1 доработки)

Выборка по умолчанию — все МО верхнего уровня справочника СберИндекса (2 594 действующих в 2024 г.;
в сеть года попадают МО с полным набором признаков). ДФО и каждый федеральный округ — пресеты.

## Замеры «до/после» (2022 г., одна сеть, k = 6)

| шаг | ДФО (226 МО) | Россия (2 219 МО) | что сделано |
|---|---|---|---|
| признаки + сеть года (kNN + MST) | 0,1 с | 1,6 с | — |
| плотные матрицы D, W, A в памяти | 1,2 МБ | 118 МБ | кэш сетей в интерфейсе — не больше 4 сетей (было 16) |
| k-means / Уорд / гауссовы смеси | 0,05–0,3 с | 0,06–0,08 с | — |
| Leiden (подбор γ) / спектральная | 0,6 / 0,1 с | 0,5 / 0,3 с | — |
| **KEFRiN** (n_init = 10) | 0,27 с | **45 с** | на выборках > 1 000 МО — 3 старта (~13 с) |
| CANUS (300 эпох) | ~25 с на 400 МО | ~25 с на 400 МО | в автоматической сетке — подвыборка 400 МО; полная выборка — вручную в интерфейсе |
| индексы SW, CH, S_Dbw, AVI/AVU/ANUI/MQ | ≤ 0,01 с | ≤ 0,08 с | — (квадратичность не мешает) |
| бутстрэп KEFRiN, 1 повтор (режим per_year) | 0,04 с | 17 с | по умолчанию динамика — pooled k-means (0,17 с на 17,6 тыс. МО-лет) |
| карта: GeoJSON всей России | 5,3 МБ | 5,3 МБ → **2,7 МБ** | для выборок > 800 МО — облегчённые полигоны (допуск 0,03°) |
| перебор k = 2…10 на странице «Кластеры» | автоматически | для KEFRiN/CANUS на > 1 000 МО — по кнопке | |

Конвейер на всю Россию: ВМП 90 с, сети (Россия, Россия + дороги, пресет ДФО) 32 с, сетка кластеров
(7 методов × 9 k × 8 лет) **49 мин** (KEFRiN ~85 с/год, CANUS на подвыборке ~225 с/год), динамика 29 с,
конвергенция 83 с. `run_all --quick` (без CANUS) — около 25 мин. Интерфейс: дымовые тесты всех страниц
на ДФО и на всей России — 46 с.

## Что изменилось в коде и конфигах

- `configs/network.yaml` — `sample.federal_districts: []` (вся Россия); `regions.yaml` — `default_sample: Россия`;
  `indicators.yaml` — `lq_base: Россия`; `dynamics.yaml` — выборки «Россия, ДФО» и типы по всей России.
- `configs/clustering.yaml` — KEFRiN: `large_n: 1000, n_init_large: 3`; CANUS: `grid_subsample: 400`.
- `src/clustering.py` — число стартов KEFRiN по размеру выборки.
- Скрипты отчётов: показатели (корреляции и разброс — `*_ru.csv` и `*_dfo.csv`), ВМП (сверка методов и
  чувствительность — по России; сверка с ВГП — по городам ДФО, другого ВГП у Росстата нет), сети
  (Россия, Россия + дороги, пресет ДФО), кластеры (CANUS на подвыборке), конвергенция (Россия, ДФО, типы;
  клубы Филлипса–Сула — по ДФО: алгоритм квадратичен по числу МО).
- `scripts/build_panel.py` — дополнительно пишет `data/geo/mo_simplified_coarse.geojson`.
- Интерфейс: выборка «Вся Россия» по умолчанию, пресеты всех округов, свой список субъектов; облегчённая
  карта для больших выборок; кэш сетей ≤ 4; перебор k для медленных методов — по кнопке.
- Тексты: README, DEPLOY, METHODS — вся Россия вместо ДФО.

Пресет ДФО даёт ту же сеть, что и раньше (хэш `1437b8158bdc`), — прежние результаты по ДФО воспроизводятся.
После этапа 3 (пересчёт денежных признаков в цены 2023 г.) хэши всех сетей сменились; каталоги, посчитанные в
текущих ценах, удалены. Актуальные — в `data/networks/index.csv`.
