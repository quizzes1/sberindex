# Проверки расчёта ВМП

Сгенерировано `scripts/build_gmp.py`. ВМП — **расчётная оценка команды**, не официальная статистика. Методика — `reports/METHODS.md`, раздел «Валовой муниципальный продукт».

Метод 1 (по общему ФОТ): 2013–2024; метод 2 (отраслевой): 2017–2024. ВМП — в текущих ценах; в цены базового года пересчитывается дефлятором ВРП (src/prices.py).

## 1. Сумма ВМП по МО субъекта равна ВРП субъекта

| метод | регион-лет | max |Σ ВМП / ВРП − 1| | max |Σ ВМП / ВРП(сборник) − 1| |
|---|---|---|---|
| basic | 1001 | 2.22e-16 | 2.22e-16 |
| sectoral | 673 | 4.44e-16 | 1.83e-06 |

Метод 2 распределяет ВДС по разделам; её итог совпадает с ВРП из сборника с точностью до округления Росстата (~1e-6). ВРП распределяется по МО, у которых известен ФОТ; МО без ФОТ (ЗАТО Вилючинск, Циолковский и др.) остаются без оценки.

МО России с оценкой (метод 2) по годам: 2017: 2435, 2018: 2590, 2019: 2581, 2020: 2588, 2021: 2580, 2022: 2589, 2023: 2582, 2024: 2405; в т.ч. ДФО: 2017: 228, 2018: 228, 2019: 227, 2020: 228, 2021: 228, 2022: 229, 2023: 228, 2024: 226 (из 230).
